# Getting help

| You have | Go to |
|---|---|
| A bug: Fructigen did something wrong | open a [bug report](https://github.com/VRIL-LABS/fructigen/issues/new?template=01-bug-report.yml) |
| A plan whose prediction disagrees with what a provider reported | open a [prediction mismatch](https://github.com/VRIL-LABS/fructigen/issues/new?template=03-prediction-mismatch.yml) report |
| An idea for a feature | open a [feature request](https://github.com/VRIL-LABS/fructigen/issues/new?template=02-feature-request.yml) |
| A security problem | follow [`SECURITY.md`](SECURITY.md). Do not open an issue |
| A licensing or partnership question | email **support@vril.li** |

Before opening an issue, check the [README](README.md), the design notes in the framework
repository (`docs/adr/ADR-0011`, `docs/plans/PLAN-fructigen.md`), and existing issues.

Fructigen is alpha software maintained by a small team. There is no guaranteed response time for
issues.
