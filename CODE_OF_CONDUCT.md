# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies in every project space: issues, pull requests, reviews and
discussions, and when someone represents the project elsewhere.

In short: be respectful, assume good faith, give and accept constructive feedback, and do not harass
anyone. The full text defines the expected behaviour, the unacceptable behaviour, and the
enforcement steps.

## Reporting

Report unacceptable behaviour to the maintainers at **support@vril.li**, with "Fructigen conduct" in
the subject. Reports are reviewed promptly and handled in confidence. The maintainers will respect
the privacy and security of the person reporting.

## Enforcement

The maintainers follow the Contributor Covenant's enforcement guidelines: correction, warning,
temporary ban, and permanent ban, in proportion to the behaviour.
